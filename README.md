# README-гаджет для админки Bitrix

Виджет выводит Markdown-файлы из каталога `/local/.README` в административной панели Bitrix. Каждый файл отображается отдельной вкладкой, имя вкладки формируется из имени файла без расширения `.md`. Каталог можно переопределить через настройку гаджета `DIRPATH`; отображение доступно пользователям с правами не ниже `R`.

В начале Markdown-файла можно указать служебный маркер `[//]:#(hidden)` — такой файл не попадёт в список вкладок. Также поддерживается выбор обработчика Markdown: `[//]:#(parsedown)` использует Parsedown, `[//]:#(mmd)` — Michelf Markdown. Если маркер не указан или содержит неподдерживаемое значение, применяется `parsedown`. При большом количестве файлов вкладки прокручиваются горизонтально и не растягивают страницу админки.
